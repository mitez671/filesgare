# منشأ مدل‌های سه‌بعدی

همهٔ فایل‌های `.glb` این پوشه از مجموعهٔ رسمی و آزاد **NASA 3D Resources** گرفته شده‌اند:
https://github.com/nasa/NASA-3D-Resources

به گفتهٔ ناسا این مدل‌ها «رایگان و بدون حق نشر» هستند و استفاده از آن‌ها تابع رهنمودهای رسانه‌ای ناسا است:
https://www.nasa.gov/nasa-brand-center/images-and-media
(از نشان و لوگوی ناسا برای تبلیغ یا تأیید استفاده نکنید.)

| فایل | مدل اصلی |
|---|---|
| apollo-lm.glb | Apollo Lunar Module |
| astronaut.glb | Astronaut |
| perseverance.glb | Mars 2020 Perseverance Rover |
| ingenuity.glb | Ingenuity Mars Helicopter |
| hubble.glb | Hubble Space Telescope (A) |
| jwst.glb | James Webb Space Telescope (A) |
| voyager.glb | Voyager Probe (A) |
| saturn-v.glb | Saturn V |
| shuttle.glb | Space Shuttle (A) |
| iss.glb | International Space Station (ISS) (A) |

بارگذار glTF و Draco (`_shared/models.js` و `_shared/gltf/draco/`) از three.js r149 با مجوز MIT است.
