# Gold Analyzer — تحلیل جامع چند تایم‌فریمی + یادگیری ماشین

برای یک نماد (پیش‌فرض طلا `GC=F`) بیش از ۴۰ روش تحلیلی را روی تایم‌فریم‌های **۱ساعته، ۴ساعته، روزانه و هفتگی** اجرا می‌کند،
رأی‌ها را می‌شمارد («۲۰ ابزار می‌گویند بخر، ۸ تا بفروش، ۱۵ تا صبر»)، و در نهایت با یک مدل ML سیگنال **میان‌مدت** (۱ تا ۳ هفته) می‌دهد:
`STRONG BUY / BUY / WAIT / SELL / STRONG SELL` همراه با حد ضرر و تارگت‌ها.

## نصب و اجرا
```bash
pip install -r requirements.txt
python -m gold_analyzer                       # طلا از Yahoo (GC=F)
python -m gold_analyzer --symbol HG=F         # مس
python -m gold_analyzer --symbol CL=F         # نفت WTI   (برنت: BZ=F، نقره: SI=F، یا BTC-USD، EURUSD=X ...)
python -m gold_analyzer --source mt5 --symbol XAUUSD   # مستقیم از متاتریدر ۵ (ویندوز) — مس: XCUUSD/COPPER، نفت: USOIL/UKOIL
python -m gold_analyzer --source csv --csv xauusd_h1.csv
python -m gold_analyzer --source demo         # داده ساختگی برای تست بدون اینترنت
python -m gold_analyzer --web                 # داشبورد گرافیکی (پایین‌تر را ببینید)
python -m gold_analyzer --json result.json    # ذخیره خروجی کامل
```
گزینه‌ها: `--horizon 10` (افق پیش‌بینی ML به روز)، `--no-ml`، `--no-intermarket`.

## نسخه گرافیکی (داشبورد وب)
```bash
python -m gold_analyzer --web            # سپس در مرورگر: http://localhost:8000
python -m gold_analyzer --web --open     # خودکار مرورگر را باز می‌کند
python -m gold_analyzer --html report.html   # یک فایل HTML مستقل (آفلاین هم باز می‌شود)
```
داشبورد شامل: عقربه سیگنال نهایی، حد ضرر و تارگت‌ها، نمودار شمارش رأی‌ها، امتیاز هر تایم‌فریم،
نقشه حرارتی دسته‌ها × تایم‌فریم‌ها، **نمودار کندلی تعاملی** (EMA 20/50/200، بولینگر، اوردر بلاک، حمایت/مقاومت، فیبوناچی،
فلش‌های خرید/فروش، خطوط SL/TP) با پنل امتیاز ترکیبی و RSI، کارت یادگیری ماشین و رأی تک‌تک ابزارها.
لینک صفحه قابل اشتراک است، مثلاً `http://localhost:8000/?symbol=SI=F&horizon=15`.
کتابخانه نمودار (TradingView Lightweight Charts) داخل پروژه است، پس نمایش نمودار به CDN نیاز ندارد.

## اجرا روی گوشی (Termux)
1. Termux را از F-Droid نصب کنید.
2. یک‌بار:
   ```bash
   pkg install git -y && git clone https://github.com/mitez671/filesgare && cd filesgare
   bash termux_setup.sh
   ```
3. دفعات بعد: `cd filesgare && python -m gold_analyzer --web --open`
4. مرورگر گوشی را روی `http://localhost:8000` باز کنید. دستگاه‌های دیگر در همان وای‌فای هم با آدرسی که در ترمینال چاپ می‌شود وصل می‌شوند.

نکته‌ها:
- اگر نصب scikit-learn روی گوشی ممکن نشد، برنامه خودکار از مدل داخلی NumPy استفاده می‌کند.
- آموزش مدل ML روی گوشی ممکن است ۱ تا ۲ دقیقه طول بکشد؛ برای سرعت تیک «یادگیری ماشین» را بردارید.
- برای دریافت داده Yahoo اینترنت (و در صورت فیلتر بودن، VPN) لازم است. گزینه «داده آزمایشی» بدون اینترنت کار می‌کند.

## اجرا روی وب (بدون Termux)
روی هر سرور یا هاست پایتون (VPS، Render، Railway، PythonAnywhere و ...) کافی است این دستور اجرا شود (`Procfile` آماده است):
```bash
pip install -r requirements.txt
python -m gold_analyzer --web        # پورت از متغیر PORT خوانده می‌شود
```
بعد از هر گوشی‌ای با آدرس سرور در مرورگر باز می‌شود.

## منطق تصمیم
1. هر ابزار برای هر کندل رأی می‌دهد: `+1` خرید، `-1` فروش، `0` صبر (فقط با داده‌های گذشته، بدون نگاه به آینده).
2. در هر تایم‌فریم ابتدا میانگین هر دسته و سپس میانگین وزنی دسته‌ها گرفته می‌شود (تا ۱۳ ابزار روندی بقیه را غرق نکنند).
3. تایم‌فریم‌ها وزن‌دهی می‌شوند: روزانه 0.40، هفتگی 0.25، ۴ساعته 0.25، ۱ساعته 0.10.
4. **مدل ML** (RandomForest + HistGradientBoosting + Logistic Regression با رأی نرم؛ بدون scikit-learn یک رگرسیون softmax با NumPy) روی تاریخچه روزانه، رأی همه ابزارها در روزانه و هفتگی + مقادیر خام اندیکاتورها + داده بین‌بازاری را
   ورودی می‌گیرد و یاد می‌گیرد که حرکت ۱۰ روز بعد صعودی، نزولی یا خنثی بوده. اعتبارسنجی به‌صورت Walk-Forward است و دقت واقعی خارج از نمونه گزارش می‌شود.
5. امتیاز نهایی = ترکیب رأی‌گیری و احتمال ML؛ وزن ML بر اساس دقت خارج از نمونه‌اش تعیین می‌شود. اگر روزانه و هفتگی مخالف باشند سیگنال یک درجه تضعیف می‌شود.
6. حد ضرر ۱.۵ ATR روزانه، تارگت‌ها ۱.۵ / ۳ / ۴.۵ ATR.

کنار هر ابزار در تایم‌فریم روزانه «دقت تاریخی» آن (درصد دفعاتی که جهت رأی با حرکت ۱۰ روز بعد یکی بوده) نمایش داده می‌شود.
