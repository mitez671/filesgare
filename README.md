# filesgare — فایل‌گاه

مجموعهٔ پروژه‌های من. بخش اصلی آن **vr-games** است: ۷۹ بازی و محیط واقعیت مجازی (WebXR) به زبان فارسی که فقط با مرورگر (و هدست VR مثل Quest) اجرا می‌شوند، بدون نیاز به ساخت (build) یا نصب.

نشانی زندهٔ بازی‌ها: https://mashghbazi.ir/game/vr-games/

## محتوای ریپو

| مسیر | توضیح |
|---|---|
| `vr-games/` | همهٔ بازی‌ها و محیط‌های سه‌بعدی (HTML + three.js r149) |
| `anarshekan/`، `zarb-shamshir/` | نسخهٔ مستقل دو بازی |
| `phone-agent/` | عامل اندرویدی و سرور MCP (با workflow ساخت در `.github/workflows`) |
| `scripts/` | اسکریپت‌های ترموکس برای انتقال به هاست (FTP) |
| `m.zip` | آرشیو قدیمی |
| `README.md` | همین فایل |
| `CLAUDE.md` | راهنمای کار برای Claude و هر برنامه‌نویس تازه‌وارد |
| `FILEMAP.md` | نقشهٔ کامل: هر فایل کجاست و چه کاری می‌کند |

## اجرای محلی

```sh
cd vr-games/..            # پوشهٔ والد vr-games
python3 -m http.server 8000
# سپس: http://localhost:8000/vr-games/
```

برای هدست، نشانی را روی HTTPS باز کنید (WebXR فقط روی HTTPS یا localhost کار می‌کند).

## انتقال به سایت

۱. فایل zip پروژه را بسازید و در پوشهٔ Download گوشی بگذارید.
۲. در ترموکس: `bash scripts/deploy-vr.sh` (نام کاربری و رمز FTP را می‌پرسد و ذخیره نمی‌کند).
۳. دانلود عکس‌ها و مدل‌های سنگین از سمت سرور: `bash scripts/get-assets.sh models photos tour museum`
۴. اگر نسخهٔ قدیمی دیده شد (کش): `bash scripts/fix-cache.sh` و صفحه را در پنجرهٔ ناشناس باز کنید.

نکتهٔ مجوز فایل‌ها: پوشه‌ها باید `755` و فایل‌ها `644` باشند؛ اسکریپت‌ها خودشان این را اعمال می‌کنند (`--no-perms`).

## بازی‌ها (خلاصه)

فضا و علم (ماه، مریخ، ناسا، ایستگاه فضایی، منظومهٔ شمسی، کهکشان، مولکول‌ها، جدول تناوبی)، جهان و سفر (زمین‌نما، سفر ۳۶۰، برج‌های جهان، پروازهای زنده، زمین‌لرزه‌ها، آب‌وهوا)، هنر و موسیقی (نگارخانه، گنجینه، موزهٔ کلیولند، پیانو، سنتور، طبل، باغ شعر)، ورزش و مهارت (بسکتبال، بولینگ، دارت، گلف، پینگ‌پنگ، دروازه‌بان…)، و بازی‌های فکری (دوز، چهارتایی، هزارتو، سایمون، روبیک…). فهرست کامل با نام پوشه در `FILEMAP.md`.
